# Embervale Companion - encerramento da C4 (2026-11-02)

**Estado: projeto experimental descontinuado / arquivado.**

A integracao com o Shroudtopia foi desenvolvida como prototipo para Enshrouded.
Ela depende de estruturas internas, assinaturas de codigo e offsets especificos do
executavel. Uma atualizacao posterior do jogo invalidou essa compatibilidade.
**Nao considere o codigo seguro ou funcional nas versoes atuais do jogo.**

## O que foi comprovado no executavel anteriormente testado

- Captura da apresentacao Vulkan por meio do Shroudtopia, sem Vulkan Loader Layer externo.
- Desenho de teste na tela e recuperacao apos recriacoes de swapchain (C4-S17).
- Ponte nativa de inicializacao, sem os scanners de memoria historicos (C4-S16/S20).
- API publica inicial `Embervale_GetApi` (C4-S18).
- Armazenamento isolado por modulo, API v1.1, com testes automatizados (C4-S19).
- Notificacao temporaria de desenvolvimento (C4-S21).

## Limites e trabalho nao concluido

- A nova atualizacao do Enshrouded quebrou a integracao; nao foi feito um novo mapeamento.
- Os hooks e os caminhos Vulkan sao experimentais; nao usar com hot reload.
- A seguranca do descarregamento, a API grafica para outros modulos e a integracao
  de DLLs independentes nao foram concluidas.
- A separacao definitiva do Core e o modulo World Map nao foram finalizados.
- A etapa C4-S22 foi preparada como perfil headless; sua validacao no jogo nao foi
  registrada antes do encerramento.
- Artefatos compilados, arquivos ignorados pelo Git e scripts de Downloads nao
  sao automaticamente incluidos neste snapshot.

## Historico

O trabalho foi preservado na branch `feature/c4-shroudtopia-bridge` e em uma tag
`archive/c4-shroudtopia-2026-11-02`. Nao foi integrado a `dev`.
Este repositorio e um registro tecnico do prototipo, nao um mod pronto para instalar.
